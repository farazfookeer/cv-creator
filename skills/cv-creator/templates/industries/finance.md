# Finance / accounting overlay

Apply on top of any region template.

## Section emphasis

- **Certifications** — promote up. CFA, CPA, ACCA, CAIA, FRM, Series 7/63/66, Chartered Accountant — the gating credentials of the field.
- **Quantified impact** in bullets is non-negotiable. Finance hiring managers expect numbers (AUM, deal size, P&L, variance, cost reduction).
- **Education matters more than in tech.** Institution + GPA + concentration stay on the CV longer in finance careers.
- **Deal sheet** for IB / PE / VC / M&A roles — list named transactions if NDAs allow (anonymize otherwise: "Advised $XXX M consumer-goods carve-out").

## Must-haves by sub-vertical

| Sub-vertical | Foreground |
|---|---|
| Investment banking | Deal experience, league tables, technicals (modeling, valuation), GPA |
| Equity / credit research | Coverage list, models built, publication record |
| Asset management | AUM managed, performance vs. benchmark, attribution |
| Private equity / VC | Deals sourced/led, portfolio company outcomes, sector thesis |
| Corporate finance / FP&A | P&L scope, forecast accuracy, system implementations (SAP, Oracle, NetSuite) |
| Audit / Big 4 | Engagement scope (revenue, assets), industries, ICFR/SOX work |
| Risk / compliance | Frameworks (Basel III, IFRS 9, SR 11-7), regulatory exam outcomes |
| Trading | Markets covered, P&L, Sharpe/IR, risk limits |

## Finance-specific gotchas

- **GPA stays on for longer** than in other industries — keep through MBA + ~3 years post if ≥3.5/3.7.
- **Deal sheets** are evaluated. List 5–8 named (or anonymized) transactions for IB/PE candidates with role and size.
- **Software:** Excel goes without saying — only mention if you have advanced specific skills (VBA, Power Query, complex modeling). Bloomberg, FactSet, CapIQ, Refinitiv: list only if you actually used them daily.
- **Tense and discipline:** Finance CVs are conservative. Past tense for past roles, no creative formatting, serif font, traditional layout. Save the design flair for creative roles.
- **Confidentiality:** Don't list deal counterparties under NDA. Anonymize size + sector + role.
- **Region-specific certifications:** UK → ACA / ACCA / CIMA, not CPA. EU → varies by country. UAE → CPA US + local membership common, plus specific DFSA registration for DIFC.
- **MBA:** Worth foregrounding if from a top program; lead with school + concentration + clubs/leadership if recent grad.
