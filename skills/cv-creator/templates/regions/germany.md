# Germany — Lebenslauf skeleton

**Length:** 1–2 pages (tabellarisch — tabular). Entry-level: 1; experienced: 2.
**Photo:** Yes, by convention — top-right of page 1. Professional headshot, neutral background. Increasingly optional at international/tech firms but still expected at traditional/Mittelstand employers. Default: include unless user specifies otherwise.
**Personal details:** Name, address (full Strasse/PLZ/City), phone, email. DOB and Geburtsort (place of birth) traditional and still common. Nationality if non-EU. Marital status optional and trending out — default omit unless user insists.
**Date format:** DD.MM.YYYY or MM/YYYY. Always include both start and end.
**Bullets:** Tabellarisch style — short, factual, less self-promotional than US. "I am amazing at X" reads as unprofessional in DE; let the verbs and metrics carry it.

## Section order (default)

1. **Persönliche Daten** (Personal details — top-left, photo top-right)
2. **Berufserfahrung** (Professional experience)
3. **Ausbildung** (Education — Hochschulausbildung first, then Schulbildung)
4. **Weiterbildung** (Continued education / certifications)
5. **Sprachkenntnisse** (Languages, with CEFR levels)
6. **EDV- / IT-Kenntnisse** (Computer skills)
7. **Hobbys / Interessen** *(optional, brief)*
8. **{{Ort}}, {{Datum}}** + **handwritten signature** at the bottom — traditional, still expected on formal applications

## Region-specific gotchas

- **Photo expected** unless target is an explicitly anonymous-process employer or a Berlin/Hamburg international tech firm. When in doubt, include.
- **German grade scale:** 1.0 (best) – 5.0 (fail). Don't translate to GPA; German recruiters read 1,7 fluently.
- **Tabellarisch beats prose.** Bullets are short, factual: "Verantwortlich für die Einführung von SAP S/4HANA bei 3 Tochtergesellschaften (Umsatz 50 M€)" — not "I led an exciting transformation journey."
- **Signature + date** at the bottom of page 2 is traditional and still appreciated on formal applications. Insert as image; don't omit.
- **Anschreiben:** Cover letter is a separate, expected document in DE — out of scope for this skill but mention to the user that they'll likely need one.
- **Decimal commas:** German notation uses "1,7" not "1.7" — important when listing grades.
- **Lückenlosigkeit:** Gaps in your timeline must be explained ("Elternzeit", "Sabbatical", "berufliche Neuorientierung"). Don't leave silent gaps.
